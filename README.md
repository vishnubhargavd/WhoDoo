WhoDoo

WhoDoo is a platform for managing student organizations in one place. It helps teams organize events, manage members, coordinate volunteers, track tasks, and handle finances without having to juggle multiple tools.

Features

Event management — Organize events and manage registrations.
Member management — Keep track of members and their participation.
Task management — Assign responsibilities and track progress.
Volunteer coordination — Manage volunteer activities and contributions.
Ticketing — Support event registration and ticket management.
Finance tracking — Keep organizational expenses and budgets organized.
Project Structure

The repository includes the following directories:

app/ — Application code
web/ — Web application
frontend_design/ — Frontend design resources
migrations/ — Database migrations
scripts/ — Utility and development scripts
tests/ — Tests
Getting Started

Clone the repository:

git clone https://github.com/vishnubhargavd/WhoDoo.git
cd WhoDoo
Follow the setup instructions for the application you want to run. Check its configuration and dependency files for the required environment variables, installation commands, and development scripts.
